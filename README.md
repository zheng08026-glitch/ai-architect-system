# ARCHITECT AI SYSTEM

AI 建築快速渲染平台封閉測試版入口。

## 部署方式

這是一個純靜態網站，可直接部署到 Cloudflare Pages。

- Build command: 留空
- Build output directory: `/`
- Root directory: `architect-ai-site`

## 本機預覽

```powershell
python -m http.server 4173
```

然後開啟：

```text
http://127.0.0.1:4173
```

## 目前狀態

- 首頁與五種介面色系
- A1-A9 生成系統展示
- AI 建築工作台前端原型
- 會員方案展示
- 封閉測試入口基礎
