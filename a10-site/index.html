定位基地

預設使用 OpenStreetMap；Google Maps 為選用服務。

街道圖僅供定位，並非航照成果。

載入後請檢視並確認範圍，不會自動生成。此示範使用獨立來源資料，非 Google 或臺灣精度驗收。

按下搜尋才會傳送到 Photon 公開服務。不自動補全；請勿輸入機密資訊。

輸入地址開始，或切換地圖直接選取。

請確認標記位置

搜尋結果不保證精確門牌。可拖曳標記修正，再確認位置。

移動、縮放地圖至基地附近，再點選矩形的兩個對角。手機也可點兩次完成。

02

調整範圍

尚未選取

來源高度優先，再以樓層估高；仍無高度者採指定示意高度，非實際建築高度。指定示意高度的量體使用白色半透明（50% 不透明度）；來源高度與樓層估高保持不透明，依高度依據分群。街廓與道路示意面預設顯示，頂面貼合航照；全模型 X 光及霧化關閉。街廓模型由地面向上建立 0.15m 示意底板，不是實測高差。

每次工作取一張框選範圍影像，保留來源標示；不提供獨立航照下載。來源無法取得時會列入缺漏報告。

街廓依道路寬度推估，不是地籍或實測邊界。捷運先顯示路線，高架與地下高程不推定。

只影響街廓頂面，不影響地面航照；未取得航照時使用灰色。2 × 2 公里為 4 km²，資料與建模時間依密度增加。

預設忽略地勢，建物基底 Z=0；需要地形起伏時再選含高程輸出。

    開發／進階工具

    匯出已確認範圍的 JSON 請求，供後端整合。這不是模型或航照圖，也不會建立生成任務。

    Google 地址候選與其自動定位框僅供 Google 地圖參考，不納入通用 JSON。請重新手動畫出自訂範圍；正式生成仍須獨立授權資料。

    目前使用的資料來源

    • OpenStreetMap contributors：街道底圖、建築輪廓／高度／樓層、道路與軌道路線；向 Overpass API 取得模型向量資料。
    • Photon（komoot）：地址與地標搜尋。
    • 內政部國土測繪中心 PHOTO2：正射影像底圖及模型航照貼圖；依使用者選項取得，拍攝日期與原始解析度未知。
    • 內政部 20 公尺網格數值地形模型：含高程模式使用；目前臺北來源為 2006 年歷史資料，TWVD2001 高程基準。全平面模式不使用地形高程。
    • 程式推導：樓層 × 指定層高、缺高建築指定高度、道路寬度與街廓底板皆為示意，並非新增實測資料。Google 未用作本模型資料來源。
    資料來源與整合邊界

    OSM 模式：© OpenStreetMap contributors 底圖與 Photon 地址服務。Google 模式：官方 Maps JavaScript API 與 Geocoding API，需由網站管理者自行設定金鑰、啟用所需 API 與計費。兩種模式均僅用於定位，地址結果需人工確認。

    Google 候選與自動定位框僅在 Google 地圖呈現，不作通用資料輸出。手動畫出的範圍是使用者自訂選取，不代表已驗證地籍或取得模型資料授權。本模組不抓取 Google 影像、地形、建物或 3D，不提供 Google 影像下載。

    正式生成前，須確認獨立航照／地形／建物來源的涵蓋範圍、時效、解析度及下載再散布授權。建築來源高度、楼層估高與指定示意高度分別標記；無法處理的例外另附清單。

    工作主機實驗流程可檢查覆蓋限制、送出 job、查詢狀態並下載已驗證成果；需明確啟用工作主機工作程序與既有 SketchUp Desktop 授權。使用 AIAS 登入與全功能開通權限，與 A10-V1 共用排隊。
